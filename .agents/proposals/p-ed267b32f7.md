A local preview server is an environment with its own behaviour: where it serves layouts or redirects differently from the host, a check run against it passes for the preview's reason, and a document that states the host's behaviour from vendor documentation states something the local check cannot show. The host's behaviour is checked on the host, or marked as an assumption.

## Evidence

A second carrier, same owner. A static site's local preview served both page layouts (a file per route and a folder per route) alike and did not redirect a trailing slash as the host does, so the local check could not distinguish them; a fresh review found the read-me stating as fact, from vendor documentation, how the host serves one layout. A manual upload of the build through the provider's dashboard skipped the deploy tool's configuration, so routing differed from the configured deploy; only a check against the live site showed it. The preview server was then made to redirect as the host does.
